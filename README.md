# 🌻 여름방학 용돈 모으기

클릭 한 번으로 즐기는 방치형(클리커) 용돈 모으기 게임. 30일 안에 목표 금액 50만원을 모으세요!

## 실행 방법

이미지까지 전부 하나의 `index.html` 파일 안에 base64로 들어있어서, 별도 설치나 빌드 없이 브라우저에서 파일만 열면 바로 실행됩니다.

- **로컬에서**: `index.html`을 더블클릭해서 브라우저로 열기
- **GitHub Pages로 배포**:
  1. 이 저장소를 GitHub에 업로드
  2. Settings → Pages → Branch를 `main`(또는 사용 중인 브랜치), 폴더는 `/ (root)`로 설정
  3. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 에서 바로 플레이 가능

## 게임 방법

- 왼쪽 큰 버튼을 눌러 알바를 뛰고 돈을 벌어요. 빠르게 연타하면 콤보 배율이 붙어요.
- 오른쪽 상점에서 전단지 알바, 편의점, 과외, 유튜브, 주식투자를 구매하면 클릭 없이도 자동으로 돈이 모여요.
- 30일(배속 버튼으로 x1~x3 조절 가능) 동안 목표 금액 50만원을 모으는 것이 미션이에요.
- 매일 랜덤 이벤트가 발생해요. 돈을 쓰면 기분이 올라가고, 아끼기만 하면 기분이 떨어져요. 기분이 낮으면 버는 돈도 줄어드니 저축과 소비의 균형이 중요해요.
- 확률형 위기 이벤트는 선택 후 "두근두근... 확인 중" 연출과 함께 결과가 확률적으로 결정돼요.
- 이벤트에는 6초 타임어택이 있어서, 망설이면 자동으로 안 좋은 결과로 넘어가요.
- Day 22 이후 목표 페이스보다 뒤처지면 게이지가 빨갛게 경고 표시돼요.
- 게임이 끝나면 S~D 랭크가 나오고, 최고 기록은 브라우저에 저장돼서 다음에도 이어서 도전할 수 있어요.

## 기술 정보

- 순수 HTML/CSS/JavaScript로 작성된 단일 파일 (프레임워크·빌드 도구 없음)
- 캐릭터 표정 이미지 4장(기분 단계별)과 로고 이미지가 모두 base64로 인라인되어 있어 외부 이미지 파일이 필요 없음
- 최고 기록은 브라우저의 `localStorage`에 저장됨 (기기/브라우저별로 별도 저장)

## 이미지 라이선스

캐릭터 표정 이미지와 로고 이미지는 제작자가 생성형 AI로 직접 만든 이미지로, 별도 라이선스 없이 자유롭게 사용 가능합니다.
